# tetronos-install

Installer for TetronOS: copies the live squashfs to disk (ext4), sets up grub (UEFI and BIOS), creates the user, keeps the ssh policy of the live ISO. TUI first, unattended later. Local only until v1.

Plan and decisions: ~/code/tetron-os/DO-NOT-COMMIT/IDEAS_TetronOS_install_path_from_live_engine_ui_and_scope.md (sections 10 and 11).
